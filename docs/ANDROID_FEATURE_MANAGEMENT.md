# 安卓开关管理与插件

## 开关管理与布局

设置页的「开关管理」默认包含通知、消费趋势和屏幕常亮。消费趋势控制账单页图表的显示，屏幕常亮默认关闭，开启后只在前台使用页生效。背景装扮和运行日志默认在设置页单独显示。

首页、「我的」和设置共享编辑状态。开关可在组内排序、移出或放回，独立卡片可在「我的」和设置之间移动。隐藏卡片只调整布局，功能开关由相应卡片管理。升级时迁移原有排列和隐藏设置，移出组的卡片会保持在所选位置。

## 通知权限与渠道

「通知」保留 App 内总开关。开启后可点卡片说明进入系统设置。系统未允许通知时，说明以橙色显示「系统未允许通知，点击前往设置」。从系统设置返回时重新检查权限。关闭 App 内总开关后，用水监控继续使用系统要求的前台服务。

App 沿用以下渠道 ID，系统已保存的提醒偏好继续生效。

| 渠道 ID | 系统显示名称 |
|---|---|
| `linyu_in_use` | 使用状态 |
| `linyu_in_use_quiet` | 后台提示 |
| `linyu_events` | 用水提醒 |
| `linyu_alert` | 横幅提醒 |
| `linyu_alert_quiet` | 重要提醒 |

旧版关闭的分项通知会继续按原设置处理。开着总开关且存在旧限制时，可以点「恢复分项通知」，取消 App 内的旧限制。系统权限和渠道偏好仍由 Android 管理。

## 插件安装与卸载

初次安装 App 时自带五项插件。绑定寝室可按需安装，旧版已有的寝室绑定会迁移为已安装插件。

| 插件 | 功能 |
|---|---|
| 附近设备 | 显示首页和 2×4 小组件的附近设备入口 |
| 消费趋势 | 在账单页查看近 7 天或本月的每日消费 |
| 屏幕常亮 | 在前台使用页保持屏幕亮起 |
| 背景装扮 | 设置主页和使用页的自定义背景 |
| 运行日志 | 记录、查看和导出脱敏日志 |
| 绑定寝室 | 从「选择附近」选择寝室，首页、小组件和快捷开水按同一规则筛选 |

「插件管理」支持查看详情、排序、检查更新和卸载，可从目录安装或从本机导入。删除附近设备会隐藏相应入口，水控所需的蓝牙连接仍可使用。删除背景装扮会清理两套自定义背景。删除绑定寝室会清理绑定并刷新小组件，上次使用记录和活动订单保留。

## 插件收录与发布

作者可通过 GitHub Issue 提交插件 ZIP，也可通过 PR 提交配置。收录后发布版本化文件并更新 `catalog.json`。本地安装支持 JSON 清单或仅含根目录 `manifest.json` 的 ZIP。目录优先从 Gitee 获取，通信或校验失败时尝试 GitHub。安装包会核验目录记录的 SHA-256 和清单内容。
